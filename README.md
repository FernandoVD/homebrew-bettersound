# Fernandovd Bettersound

## How do I install these formulae?

`brew install fernandovd/bettersound/<formula>`

Or `brew tap fernandovd/bettersound` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "fernandovd/bettersound"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
