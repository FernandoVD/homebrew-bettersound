# fernandovd/bettersound

Homebrew tap for [BetterSound](https://github.com/FernandoVD/BetterSound), a
Control Center-style volume mixer for the macOS menu bar.

## Install

```bash
brew tap fernandovd/bettersound
brew install --cask bettersound
```

Requires macOS 26 (Tahoe) or later. This build is ad-hoc signed, not
notarized, so the first launch needs a right-click → Open (or
`xattr -cr /Applications/BetterSound.app`) to get past Gatekeeper.
